# Groth16 zkSNARK 完整示例

这个示例展示了一个完整的 Groth16 zkSNARK 工作流程，实现了一个**平方根证明电路**。

## 功能概述

该示例实现了问题陈述中要求的所有功能：

### 1. 约束电路设计 ✅
- 实现了平方根证明电路：证明知道某个数 `y` 的平方根 `x`
- 约束：`x * x = y`
- 公开输入：`y` (平方值)
- 私密输入：`x` (平方根)

### 2. 可信设置生成 ✅
- 使用 BLS12-381 椭圆曲线
- 生成证明密钥和验证密钥
- 包含详细的性能计时

### 3. 零知识证明生成 ✅
- 基于私密输入生成证明
- 证明者知道平方根但不泄露具体值
- 使用随机数确保零知识特性

### 4. 证明验证 ✅
- 仅使用公开输入验证证明
- 快速常数时间验证
- 验证成功确认证明者知道平方根

### 5. 完整错误处理 ✅
- 包含适当的错误处理
- 安全性演示：错误的输入无法生成有效证明
- 详细的输出信息和性能指标

## 技术规格

- **椭圆曲线**: BLS12-381 (256位安全性)
- **证明系统**: Groth16 zkSNARK
- **约束数量**: 1个 (x * x = y)
- **公开输入**: 1个 (y)
- **私密见证**: 1个 (x)

## 运行示例

```bash
cd groth16
cargo run --example basic-groth16 --features="std"
```

- ✅ **完整性**: 有效证明被接受
- ✅ **可靠性**: 无效证明被拒绝  
- ✅ **零知识**: 秘密值保持隐藏
